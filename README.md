# SQL2095

> **NOTE:** This project is still a work in progress, so parts of this README and the codebase as a whole may be incomplete or missing entirely.

SQL2095 is a very basic, minimal dialect of SQL intended as a personal learning project. The goal with this is not to create a fully-featured database application, but rather to build, from scratch, an application which can:

- Create/drop tables, as well as add/drop/rename existing columns
- Select/insert/delete/update records
- Utilize a page buffer and B+ tree indexing for improved performance
- Persist between runs by saving to disk
